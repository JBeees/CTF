# TITLE : Time Traveller 
## Author : muhammetadibas
## Description
Let's take a trip to nasa.gov on December 31, 1996. If you can tell me what email NASA listed on their website, I'll provide you with 10 points. Format: CTFlearn{email}
## Solution
In this challenge, I first accessed the Wayback Machine at:
```
https://web.archive.org
```
Using the Wayback Machine, I opened `nasa.gov` and selected the snapshot dated `December 31, 1996`. From that archived version of the website, I found the email address `today@nasa.gov`, which was the required answer for the challenge.
