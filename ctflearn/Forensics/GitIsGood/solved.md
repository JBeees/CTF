# TITLE : Git Is Good
## Author : intelagent
## Description
The flag used to be there. But then I redacted it. Good Luck.
## Solution
We were given a ZIP file containing a GitHub repository. After extracting the ZIP, I found that it included the `.git` directory. By navigating into the repository and using the `git show` command, I was able to inspect the commit history. From there, I discovered the real flag stored in a previous commit.
