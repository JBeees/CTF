# TITLE : file-run1
## Author : Will Hong
## Description
A program has been provided to you, what happens if you try to run it on the command line?
Download the program here.
## Hints
- To run the program at all, you must make it executable (i.e. `chmod +x run`)
- Try running it by adding a '.' in front of the path to the file (i.e. $ ./run)
## Solution
We received a binary file but didn’t have permission to execute it. To give it execution permission, I ran: `chmod +x run` After that, I executed the file with: `./run` As a result, you will get the flag.
